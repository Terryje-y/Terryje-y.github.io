About the Engine

Can I use the News AI Engine today?

The engine runs privately for our own channels while we improve it. If you would like early access or a demo, send us a message through the contact page.

Which platforms does it support?

Vertical 9:16 video for TikTok and Shorts, and 16:9 video for YouTube. TikTok uploads use TikTok's official Content Posting API.

Does it post without my permission?

No. The default mode only renders videos. Uploading as a draft or posting directly must be chosen by you before a batch starts.
